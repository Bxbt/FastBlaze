        Template syntax
        
    
          
    {thaiid}Random valid Thai ID. Options: prefix=8, format=dash
    
          
    {random-number: min=0; max=9}Random integer (rounded=no for decimals)
    
          
    {x=5} {y={random-number: min=1; max=9}}Set a variable
    
          
    {=x*2 + floor(y/3)}Insert expression. & joins text, functions: floor ceil round abs min max mod len upper lower
    
          
    {formtext: name=first; default=ทดสอบ}Ask before inserting. Also {formmenu: default=A; B; C; name=x}, {formparagraph}
    
          
    {import: /id}Insert another snippet
    
          
    {click: selector=[data-testid="x"]}Wait (up to 5s) for a visible element, click it; text after it types into the focused field
    
          
    {click: text=บางรัก}Click the element whose visible text is exactly this (add selector= to search inside it). Good for dropdown options
    
          
    {clear} {clear: selector=…}Empty the focused field (or the matched field) before typing
    
          
    {select: selector=…; value=10}Pick an option in a native <select> by value=, text= or index=
    
          
    {wait: 500ms} {key: enter}Pause; press enter / tab / escape / up / down / space / backspace
    
          
    \{ \\Literal brace / backslash
